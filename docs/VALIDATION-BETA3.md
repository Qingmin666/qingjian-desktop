# 轻笺 2.0.0-beta.3 验证

## 自动验证
- 29个JavaScript文件通过语法检查，23项测试通过。
- 新增四角、负坐标屏幕、640×480可用区域测试，覆盖三条贴靠边、两种胶囊展开状态、三种显示模式，模式切换不改变胶囊矩形。

- 问候计时器测试覆盖即时调整、暂停、恢复和不重复累积；新配置默认为橙色，旧主题兼容。
- ICO含16、20、24、32、40、48、64、128、256九个尺寸；PNG包含透明与半透明像素。

## 使用
完整解压到独立目录，退出旧版后运行QingJian.exe。在设置→色调与问候中选择原版橙或调整问候语切换间隔。0秒表示暂停自动更换。保留原目录及任务数据；通过导出/导入迁移。
