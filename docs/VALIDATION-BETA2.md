# 轻笺 2.0.0-beta.2 验证记录

## 已通过
- 28 个 JavaScript 文件语法检查。
- 18 项自动测试：旧数据迁移、排序、子任务、提醒、打包；新增侧边朝向、向内展开、顶部与侧边居中、负坐标屏幕、反复归位、悬停计时与交互保护、400条问候、设置边界。
- 独立 Windows x64 构建完成。

## 未通过本轮运行验收
- 桌面技能启动报告缺少 codex app-server；替代桌面启动未暴露测试窗口；访问资源管理器的确认超时。
- 隔离运行自检没有生成结果文件，因此不能声称托盘、通知、渲染进程恢复或实际动画在 beta.2 上通过运行测试。
- 原有 beta.1 的运行验收不能替代本版。

## 手动验收顺序
1. 三个边缘分别切换三种模式，检查悬停展开、跨窗口间隙、离开恢复。
2. 修改悬停/收回时间，打开任务日期、菜单和设置，检查操作时不收回。
3. 打开/关闭居中，反复展开收回，检查贴靠边缘与自定义位置。
4. 五套色调、昵称、四时段问候和20秒淡入淡出；侧边文字正向显示。
5. 实际连续运行，检查托盘恢复、窗口是否消失、动画是否闪烁；异常记录位于同目录 data/runtime.log，不含任务标题。

## 稳定性限制
窗口消失尚未复现。当前变更移除相互置顶并加入诊断与有限重试，不能据此宣称根因已查明或闪退已彻底消除。实际毛玻璃动画受原生宿主与桌面合成影响，仍需用户本机确认。
