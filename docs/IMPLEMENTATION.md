# 改动与设计

- src/task-core.js：浏览器与主进程共用的字段校验和排序，v1→v2 迁移；归属日期保留，dueAt/remindAt 独立。
- src/model.cjs：一层子任务、整组删除撤销、手动顺序、备份合并与冲突拒绝；设置白名单。
- src/main.cjs：双窗独立生命周期、Tray、系统 Notification、主进程提醒调度、DPI 坐标转换、稳定收起锚点。
- src/dock-geometry.cjs：纯几何与贴靠规则，显示器工作区边界。
- src/reminders.cjs：可注入时钟与计时器、重排、去重筛选、停止与唤醒复查。
- src/renderer.js：中文任务编辑器、分钟输入、拖拽、键盘排序、子任务、设置与备份。
- 原生玻璃实现保留，窗口分别以自己作为原生根，避免主任务窗隐藏时误隐藏胶囊。
- 不保留个人数据；不改全局 MCP、代理或 Codex 配置；不修改原软件安装目录。

贴靠后三种模式仅在 dockEdge 非空时生效。自由状态默认完整列表。通过胶囊右键菜单或托盘可以恢复完整视图。编辑和添加任务时临时切换完整模式，避免输入面板被窄窗裁切。
使用 performance.now() 计算动画进度；定时器间隔按屏幕刷新率和选定上限调整，并扣除工作耗时。原生窗口几何更新仍由操作系统合成；不宣称严格 VSync。
提醒会持久化 remindedAt；编辑提醒时间清除该标记；系统通知报告发送失败时清除标记，以便重试。关闭托盘之前保存窗口锚点。
