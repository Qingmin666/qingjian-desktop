# 轻笺 · QingJian

Windows 桌面待办工具，基于 TodoDuo 1.5.0 的独立定制开发版。

## 功能
- 中文界面、悬停说明、任务反馈。
- 手动拖拽与 Alt＋上下方向键排序；按截止时间、创建时间或标题自动排序。
- 独立的任务归属日期、截止时间、提醒时间，时间输入精确到分钟。
- 一层子任务，完成进度、折叠、整组删除与撤销；热力图只统计主任务。
- Windows 通知、系统托盘、双击恢复、关闭时收起、完全退出。
- 顶部及左右贴靠；仅胶囊／胶囊＋首项任务／完整列表。
- 跟随屏幕或指定帧率上限；展开收回使用稳定锚点。
- 导入旧 TodoDuo JSON 备份；导入前自动保存现有数据副本。

## MCP 接入
内置标准 Streamable HTTP MCP，默认关闭。本机在设置→MCP接入中启用后连接 `http://127.0.0.1:49321/mcp`，必须携带软件生成的 Bearer 令牌。可复制连接配置示例，根据客户端格式使用。

提供10个任务工具：信息、列表、详情、新增、修改、完成／重开、置顶、子任务移动与手动排序、删除（含级联子任务）。所有写入复用现有保存、界面刷新与提醒调度。删除不额外弹出软件确认框，二次确认应由客户端／后续Skill执行。

远程模式启用后监听IPv4所有网卡，必须设置HTTPS完整地址、PEM证书链及未加密PEM私钥；客户端需信任相应证书。不会自动配置公网、端口映射或防火墙。静态Bearer认证，不提供OAuth登录／动态客户端注册，OAuth-only客户端尚不适配。

配置和令牌保存在本机 `data/mcp-config.json`，与任务导出分开。复制配置会将令牌放入剪贴板；重置后旧令牌与会话失效。持有令牌即可操作全部任务。源码和运行包不含实际配置。

协议兼容2026-07-28逐请求元数据，以及2025-11-25、2025-06-18、2025-03-26握手。JSON响应，不提供独立SSE订阅流；不是旧版HTTP+SSE接口。接口、并发与重试规则见 docs/MCP.md。

## 升级
先退出旧版，完整解压到新目录。需要旧任务时，从旧版导出 JSON，再在新版设置中导入；不要覆盖原目录。测试版尚需在实际桌面验证闪烁、窗口消失、侧边贴靠和托盘恢复。

## 提醒
只在轻笺运行或驻留托盘时提醒。完全退出及关机后不提醒。启动与系统唤醒时检查遗漏提醒。Windows 勿扰、通知权限及便携应用通知身份可能影响显示；设置中提供测试通知。通知的分钟级输入并不保证实时硬调度。

## 使用与数据
分发目录应包含 QingJian.exe、resources、DLL 等完整运行时文件。运行后在同目录 data/todos.json 保存数据。
默认关闭窗口时收起到托盘。托盘菜单“完全退出”停止提醒。不内置账号、网络同步或自动上传。

## MCP联网验收
开发检查默认用实际HTTP处理器的内存请求验证协议，不代表真实网络连接通过。解压源码包后，正常本机可运行：
~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-mcp-network.ps1
~~~
脚本只使用独立测试数据和回环临时端口，验证真实TCP及HTTPS握手；HTTPS测试使用自签测试证书，只有测试客户端放宽该测试证书校验。不会修改正式客户端或系统信任设置。

## 开发与构建
构建需要 Windows x64 TodoDuo 1.5.0 运行时目录（含原生辅助程序）和 PATH 中的 Node.js；不执行 npm install，也不编译原生依赖。通过 `-RuntimeRoot` 或环境变量 `QINGJIAN_RUNTIME_ROOT` 指定运行时目录。
源代码无需访问真实任务数据；使用 --test-mode 和 --data-dir 指定隔离测试目录。
确认执行后：
~~~powershell
node tools/check.cjs
node --test
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -RuntimeRoot "C:\path\to\TodoDuo-Windows-x64"
.\dist\QingJian\QingJian.exe --test-mode --data-dir=.\test-results\profile
~~~
生产版运行时不加 --test-mode（普通测试模式不发送到期通知）。
